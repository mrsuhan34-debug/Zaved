# Dry Fruits Website

A fast, mobile-friendly static website for a dry fruits business. No build step, no backend.

## Features
- Product catalog with category filter
- Weight options (250g / 500g / 1kg) with auto pricing
- Cart (saved in browser) and one-tap order via WhatsApp
- Responsive design, SEO-ready basics

## Customize
Open `script.js` and edit the `CONFIG` block (brand name, WhatsApp number, phone, email, currency) and the `PRODUCTS` list.

## Run locally
Just open `index.html` in a browser.

## Deploy free on GitHub Pages
1. Push these files to a GitHub repo (root folder).
2. Repo > Settings > Pages > Source: `main` branch, `/ (root)`.
3. Your site goes live at `https://<username>.github.io/<repo>/`.
